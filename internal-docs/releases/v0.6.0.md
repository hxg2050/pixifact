# Pixifact v0.6.0

本版本建立 AI Agent 对真实 Vite Web 游戏的运行时观测与输入闭环，并完善浏览器 Editor 的资产和人工微调工作流。

## 已发布包

- `pixifact@0.6.0`
- `pixifact-cli@0.6.0`
- `create-pixifact@0.6.0`

## 亮点

- 新增 Agent Runtime：外部 Agent 可以发现运行页面，读取真实 PixiJS 节点树、节点详情、显式业务状态和增量日志，并发送标准 pointer / keyboard 输入。
- 新增 `pixifact runtime tree --output <json-path>`，把完整节点树保存为带采集时间和 Runtime ID 的 JSON 快照，避免大型节点树占满终端上下文。
- 新增 `pixifact editor screenshot --output <png-path>`，输出当前 Authoring Scene 的设计尺寸 PNG，不包含 Editor UI。
- Editor 资产面板改为项目目录树，支持图片缩略图、图片资源拖放到 Inspector 字段，以及常用画布和编辑快捷键。
- 明确 Compiler locator 来源，并精简 `scene validate --all` 成功输出，降低 Agent 命令噪声。
- 更新 Pixifact Skill，加入 Scene 修改、Runtime 查询、标准输入和 state / logs 前后验证闭环。

## Runtime 边界

- Runtime 仅支持 Vite Web 开发模式，不接入 Editor Authoring Preview、production build 或微信小游戏。
- 节点树直接来自当前 `app.stage`，不建立第二棵 Scene Instance 树。
- Runtime 不提供 eval、节点 mutation、业务状态 mutation 或方法调用。
- `runtimeId` 和 PixiJS `uid` 只对当前运行实例有效，页面刷新后必须重新发现并生成节点树快照。

## 安装

```bash
bun create pixifact my-game
cd my-game
bun install
bun run build
```

已有项目升级：

```bash
bun add pixifact@^0.6.0
bun add -d pixifact-cli@^0.6.0
```
