# Pixifact v0.13.0

本版本改进浏览器 Editor 的画布操作、保存方式和多 Scene 编辑。

## 发布包

- `pixifact@0.13.0`
- `@pixifact/platform-wechat@0.13.0`
- `@pixifact/platform-douyin@0.13.0`
- `pixifact-cli@0.13.0`
- `create-pixifact@0.13.0`

## 变更

- 画布左上角新增拖动画布、移动节点和调整大小三种工具；调整大小工具保留原有的拖动节点与 resize 行为。
- Editor 默认手动保存，通过保存按钮或 Ctrl/Cmd+S 写入 Scene；左下角设置可开启自动保存。
- 一个 Editor 可打开多个 Scene 标签。各标签保留未保存草稿、Undo / Redo、选择和画布视图；关闭脏标签时提供保存、放弃和取消。
- 外部 Agent 修改 Scene 后，干净标签更新文件版本；脏标签保留草稿，保存冲突时可比较、覆盖或放弃草稿。

GitHub Release：[v0.13.0](https://github.com/hxg2050/pixifact/releases/tag/v0.13.0)。

## 安装

```bash
bun create pixifact@0.13.0 my-game
cd my-game
bun install
```

已有项目升级：

```bash
bun add pixifact@^0.13.0
bun add -d pixifact-cli@^0.13.0
```
