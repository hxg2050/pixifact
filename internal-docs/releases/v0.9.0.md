# Pixifact v0.9.0

本版本简化了新建 Scene 的 CLI 命令，并改进浏览器 Editor 资产树的初始展开状态与状态恢复体验。

## 已发布包

- `pixifact@0.9.0`
- `@pixifact/platform-wechat@0.9.0`
- `@pixifact/platform-douyin@0.9.0`
- `pixifact-cli@0.9.0`
- `create-pixifact@0.9.0`

## 变更

- `pixifact scene create <scene-path>` 直接由文件路径 basename 推导 Scene 类名，不再需要冗余的 `--scene` 和 `--name` 参数。
- 浏览器 Editor 的资产树默认收起目录，并在重开 Editor 后恢复用户此前的目录展开状态。

## 安装

```bash
bun create pixifact@0.9.0 my-game
cd my-game
bun install
bun run build
```

已有项目升级：

```bash
bun add pixifact@^0.9.0
bun add -d pixifact-cli@^0.9.0
```
