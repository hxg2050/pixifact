# Pixifact v0.11.2

本版本修复浏览器 Editor 画布中被覆盖层遮挡的 Scene 子节点无法拖拽的问题。

## 已发布包

- `pixifact@0.11.2`
- `@pixifact/platform-wechat@0.11.2`
- `@pixifact/platform-douyin@0.11.2`
- `pixifact-cli@0.11.2`
- `create-pixifact@0.11.2`

## 变更

- 修复 Editor 画布中覆盖层抢占 pointerdown，导致已选 Scene 子节点无法拖拽的问题。
- 增加覆盖节点拖拽命中回归测试。

## 发布前验证

`bun run release:check` 已通过：

- 25 个测试文件、322 项测试。
- 五个公开包构建与内容检查。
- Web、微信、抖音和双平台示例 tarball 安装与构建冒烟。

## 发布后验证

待 GitHub Actions、npm registry 和 GitHub Release 完成后补充。

## 安装

```bash
bun create pixifact@0.11.2 my-game
cd my-game
bun install
bun run build
```

已有项目升级：

```bash
bun add pixifact@^0.11.2
bun add -d pixifact-cli@^0.11.2
```
