# Pixifact v0.11.0

本版本增强浏览器 Editor 的素材定位和预览节点选择交互，改善长按拖动时的选中稳定性。

## 已发布包

- `pixifact@0.11.0`
- `@pixifact/platform-wechat@0.11.0`
- `@pixifact/platform-douyin@0.11.0`
- `pixifact-cli@0.11.0`
- `create-pixifact@0.11.0`

## 变更

- 点击 Inspector 中的素材地址可以快速定位到资产树中的对应素材。
- 预览中使用 click 选中节点，支持逐层选择底部节点；选中节点后长按拖动不会在按下瞬间误选其他节点。

## 安装

```bash
bun create pixifact@0.11.0 my-game
cd my-game
bun install
bun run build
```

已有项目升级：

```bash
bun add pixifact@^0.11.0
bun add -d pixifact-cli@^0.11.0
```
