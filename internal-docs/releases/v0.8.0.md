# Pixifact v0.8.0

本版本新增 Agent Runtime Canvas 截图能力，并修复 macOS 临时目录下 Vite 8 构建路径不一致的问题。

## 已发布包

- `pixifact@0.8.0`
- `@pixifact/platform-wechat@0.8.0`
- `@pixifact/platform-douyin@0.8.0`
- `pixifact-cli@0.8.0`
- `create-pixifact@0.8.0`

## 变更

- 新增 `pixifact runtime screenshot`，可捕获已注册 PixiJS `Application` 的 Canvas PNG。
- 省略 `--output` 时，截图默认写入项目根下 `.pixifact/runtime/frame.png`；显式 `--output` 仍可覆盖。
- CLI Vite target 和 Pixifact Vite plugin 使用 `realpath` 规范化项目根目录，修复 macOS `/var` 与 `/private/var` 路径别名导致 Vite 8 构建失败的问题。

## 发布前验证

`bun run release:check` 已通过：

- 25 个测试文件、305 项测试。
- 五个发布包构建与内容检查。
- 仓库外 tarball 安装、CLI、Scene 校验、Scene 编译、Web / 微信 / 抖音 production build 和 Editor HTTP 冒烟。

## 安装

```bash
bun create pixifact@0.8.0 my-game
cd my-game
bun install
bun run build
```

已有项目升级：

```bash
bun add pixifact@^0.8.0
bun add -d pixifact-cli@^0.8.0
```
