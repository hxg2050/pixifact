# Pixifact v0.14.0

本版本改进浏览器 Editor 的界面、层级批量操作和素材预览。

## 发布包

- `pixifact@0.14.0`
- `@pixifact/platform-wechat@0.14.0`
- `@pixifact/platform-douyin@0.14.0`
- `pixifact-cli@0.14.0`
- `create-pixifact@0.14.0`

## 变更

- Editor 调整为 macOS 风格的四栏布局：公共资产面板位于最左侧并占满工作区高度，层级、画布和检查器依次排列；默认深色，可手动选择浅色或跟随系统。
- 层级支持右键添加、复制、粘贴、删除节点，以及多选后的批量操作。拖动节点接近层级列表上下边缘时自动滚动，并持续更新放置位置。
- 多选节点后可使用十二种对齐与分布操作。
- 点击图片资产时，在检查器下方显示较大预览、路径、分辨率和文件大小。示例项目新增两张测试图片。
- 画布移动工具增加 X/Y 轴箭头与自由移动方块；资产、层级和检查器列表间距收紧。

## 安装

```bash
bun create pixifact@0.14.0 my-game
cd my-game
bun install
```

已有项目升级：

```bash
bun add pixifact@^0.14.0
bun add -d pixifact-cli@^0.14.0
```
