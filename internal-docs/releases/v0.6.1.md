# Pixifact v0.6.1

本版本完善浏览器 Editor Inspector 的布局属性覆盖、紧凑字段排版和颜色编辑稳定性。

## 已发布包

- `pixifact@0.6.1`
- `pixifact-cli@0.6.1`
- `create-pixifact@0.6.1`

## 变更

- Inspector 支持编辑 `left`、`right`、`top`、`bottom`、`horizontal` 和 `vertical` 可选布局属性。
- Inspector 按语义分区展示属性，将 `x/y` 等相关数值字段放在同一行，并让字段名与输入控件横向排列。
- 修复颜色选择器关闭后颜色草稿被改写成数字，导致颜色错误和重复提交的问题；一次 Undo 现在可以恢复修改前的颜色。

## 发布前验证

`bun run release:check` 已通过：

- 19 个测试文件、272 项测试。
- `pixifact`、Editor frontend 和 `create-pixifact` 构建。
- 三个 npm 包的内容和版本检查。
- 仓库外 tarball 安装、CLI、Scene 校验、Scene 编译、Vite production build 和 Editor HTTP 冒烟。

## 安装

```bash
bun create pixifact@0.6.1 my-game
cd my-game
bun install
bun run build
```

已有项目升级：

```bash
bun add pixifact@^0.6.1
bun add -d pixifact-cli@^0.6.1
```
