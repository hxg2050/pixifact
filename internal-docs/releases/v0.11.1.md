# Pixifact v0.11.1

本版本修复浏览器 Editor 的布局节点属性编辑和画布拖拽交互问题。

## 已发布包

- `pixifact@0.11.1`
- `@pixifact/platform-wechat@0.11.1`
- `@pixifact/platform-douyin@0.11.1`
- `pixifact-cli@0.11.1`
- `create-pixifact@0.11.1`

## 变更

- 修复 Editor 中布局节点属性编辑和画布拖拽交互的问题。

## 发布前验证

`bun run release:check` 已通过：

- 25 个测试文件、320 项测试。
- 五个公开包构建与内容检查。
- 仓库外 tarball 安装、CLI、构建和 Editor 启动冒烟。
- Web、微信、抖音和双平台示例构建。

## 发布后验证

- GitHub Actions [Publish npm packages](https://github.com/hxg2050/pixifact/actions/runs/32733071678) 已通过 Trusted Publishing。
- npm registry 已确认五个包均为 `0.11.1`。
- 从 npm registry 创建 `create-pixifact@0.11.1` 项目并使用 Bun `1.3.13` 完成 `bun install` 和 Web production build。
- GitHub Release 已创建：[v0.11.1](https://github.com/hxg2050/pixifact/releases/tag/v0.11.1)。

## 安装

```bash
bun create pixifact@0.11.1 my-game
cd my-game
bun install
bun run build
```

已有项目升级：

```bash
bun add pixifact@^0.11.1
bun add -d pixifact-cli@^0.11.1
```
