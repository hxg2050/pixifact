# Pixifact v0.10.0

本版本支持在浏览器 Editor 中修改 Scene 节点 ID，并为不合法的命名提供即时反馈。

## 已发布包

- `pixifact@0.10.0`
- `@pixifact/platform-wechat@0.10.0`
- `@pixifact/platform-douyin@0.10.0`
- `pixifact-cli@0.10.0`
- `create-pixifact@0.10.0`

## 变更

- Editor Inspector 的“节点”区域支持直接修改 Scene 节点 `id`，选区会随 ID 迁移，并支持 Undo / Redo。
- ID 为空、重复或命名不合法时，输入框显示错误状态和具体原因，避免写入无效 Scene。

## 安装

```bash
bun create pixifact@0.10.0 my-game
cd my-game
bun install
bun run build
```

已有项目升级：

```bash
bun add pixifact@^0.10.0
bun add -d pixifact-cli@^0.10.0
```
