# Pixifact v0.12.0

本版本让 AI 在 Web 游戏开发中获取更完整的视觉和运行状态反馈。

## 发布包

- `pixifact@0.12.0`
- `@pixifact/platform-wechat@0.12.0`
- `@pixifact/platform-douyin@0.12.0`
- `pixifact-cli@0.12.0`
- `create-pixifact@0.12.0`

## 变更

- 新建 Web 项目默认接入开发期 Agent Runtime，并示范可观察的业务状态。
- Runtime 节点返回 `.scene` 来源和 locator，Agent 可从运行画面定位源文件；Runtime 截图保留游戏视口变换。
- 新增 `pixifact scene screenshot --scene <path> --output <png>`，无需启动 Editor 即可获取任意 Scene 的静态预览；本机需要安装 Google Chrome。
- 加入可玩 Web 游戏示例与固定 Agent 任务评测协议。

## 验证

本地 `bun run editor:typecheck`、`bun install --frozen-lockfile --dry-run` 和全量测试通过（26 个文件、325 项）。[发布工作流](https://github.com/hxg2050/pixifact/actions/runs/35897778515) 完成测试、构建、包内容检查、下游 tarball 安装冒烟和 Trusted Publishing。npm registry 已确认五个包均为 `0.12.0`。

GitHub Release：[v0.12.0](https://github.com/hxg2050/pixifact/releases/tag/v0.12.0)。

## 安装

```bash
bun create pixifact@0.12.0 my-game
cd my-game
bun install
```

已有项目升级：

```bash
bun add pixifact@^0.12.0
bun add -d pixifact-cli@^0.12.0
```
